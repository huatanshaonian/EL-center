# EL 信号面包板实验 D0

此版用于先验证3.3V→5V逻辑、假负载与信号质量。实物尚未搭建，实验数据尚未取得。当前电源保护草稿未放行，首轮不接Sharp屏，CN5的19/20脚12V不接入信号面包板。

## 1. 实验电路

两片 SN74AHCT245N（PDIP-20）跨面包板中沟，缺口朝上；左侧从上到下1–10脚，右侧从上到下20–11脚。不要按原理图符号两侧的位置猜实物针脚；以缺口/圆点和TI顶视图识别。SOIC-20 DW 是PCB用料，首轮用N直插。

若使用标准a–e/f–j分组的830孔面包板，可将U1两列脚插在e/f列第10–19行，U2插第30–39行；此行号仅是摆放建议，先用万用表确认同排五孔连通、中沟隔离及电源轨是否中断。每片IC的20脚接局部+5V、10脚接GND，100nF直接跨接20/10脚，连线尽量短；两芯片共用10µF/50V电解（正极5V、负极GND）。共地线应先接。

|U1、U2 pin10 GND|电源GND、Dock GND、假负载GND共地|

|每路B输出|B脚→待选串阻→假负载连接端；该端100k→GND|
|每路假负载|连接端→390Ω→节点X；X→10pF→GND，X→1M→GND|

## 2. 先做静态实验

1. 断电布线，检查5V与GND无短路、IC无反插、5V未接任何Dock IO/3.3V。3.3V从Dock引入，仅作信号和OE上拉。P2的11/12、P3的6保持不连接。
2. 先不接Dock数据，断开OE控制线；在OE_N加临时10k到局部5V，使输出禁用。只用限流5V给两片芯片供电，空载可先把限流设50mA用于排查短路；异常发热或限流即断电检查。
3. 切断5V，移除临时5V上拉，再接Dock与正常3.3V上拉。先使Dock J6-8为高、J6-9 VD_ON_N为高，并让全部数据/时钟输出为低；测到状态正确后恢复局部5V。避免芯片无5V时持续向A端送高电平；1k不等于断电隔离。
4. OE高时，输出靠100k下拉应接近0V。OE低后，逐路用3.3V高/0V低验证表中对应B脚，检查没有串线、UD位序颠倒及短路。FPGA引脚只接3.3V逻辑。此时没有屏，也没有12V。

## 3. 再做动态假负载实验

先100kHz/1MHz单通道，再升到目标约5.4MHz CP2；同时输出已知数据交替码，最后采用完整扫描。面包板上长电源轨和杜邦线的寄生很大，若5.4MHz波形不合格，改短线焊接小转接板/洞洞板验证，不能只降低示波器带宽把振铃隐藏。

探头在假负载连接端（对应CN5）相对当地GND测量，用短接地弹簧，记录探头带宽和电容；不要把长鳄鱼地线产生的振铃当成真实信号。实测必须包含CP2与数据双通道相对时序。

|验收项|目标|数据|
|---|---|---|
|5V VL|4.75–5.25V，记录纹波/瞬态|待测|
|CN5逻辑高/低|高≥3.5V，低≤1.5V|待测|
|绝对峰值|−0.3V至VL+0.3V内，含过冲负冲|待测|

|禁用/复位|OE高输出低，无异常时钟|待测|

串阻值、线长、假负载、频率、探头设置均写入实验记录。仿真中100Ω边沿约12.6ns，只对该假定模型成立，不能代替这一表的实测。

## 4. 电源保护单独实验

TPS25947是小封装功率器件，不能用杜邦线跨面包板承载屏的12V/1.8A；采用评估板或焊好并检查过的转接板，以粗线端子接电子负载。该部分元件、阈值和放电/保持仍需设计闭环，不按当前D0直接给屏供电。

先以16Ω≥5W假负载验证VL；VD用电子负载逐级增加，记录启动斜率、压降、最大浪涌和短路/过压动作。分别注入VD_ON_N高、PFAIL低、VL跌落、Dock复位/断电，四通道同时观察VL、VD、CP2、OE/EN。关断必须以VD实际衰减波形作为依据：VD尚未安全降下时仍要维持VL和有效扫描。

默认锁存故障只能在原因查明后按数据手册操作复位。台式电源限流并不能保证屏内保险丝不熔断，需考虑输出电容和故障能量。现阶段不开展真屏短路/故障实验。
