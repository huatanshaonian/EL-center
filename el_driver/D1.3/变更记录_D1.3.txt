一、P1/P2/P3 与 Dock J5/J6/J14 物理排列不一致（致命，已改）
  问题：P1–P3 用的封装 HDR-TH_12P-P2.54-V-M-R2-C6-S2.54-EH 是"U 形"编号——一排 1–6，另一排 7–12 倒着回来（1 对 12）。
        Dock 3713 原理图里 J5/J6/J14 是 Conn_02x06_Odd_Even（1、2 隔排相对，都是 3V3；3、4 隔排相对，都是 GND），
        物理上与 Digilent PMOD 一样：一端两针 3V3、下一列两针 GND。
        用 2×6 成排杜邦/PMOD 延长线直插：Dock 的 GND 落到 P-2（3V3），3V3 直接对地短路；反插则 FPGA 输出顶 3V3。
  改法：
  1. 工程库封装 21c51570467c9628 焊盘重新编号为奇偶交错（与 Dock 相同）：焊盘位置不变，
     原 1→1、2→3、3→5、4→7、5→9、6→11、7→12、8→10、9→8、10→6、11→4、12→2。
  2. 原理图按"新脚号 = Dock 脚号"重新分配网络，尽量让已有走线留在原焊盘上（只动 2–3 根线/插座）：
       Dock J5 ↔ P1：1、2 = 3V3_FPGA，3、4 = GND，5 LD3，6 LD1，7 LD2，8 LD0，9 UD0，10 UD3，11 UD1，12 UD2
       Dock J6 ↔ P2：1、2 = 3V3_FPGA，3、4 = GND，5 空，6 VD_HI_N，7 空，8 VD_ON_N，9 CP2，10 OE_N，11 CP1，12 S
       Dock J14 ↔ P3：1、2 = 3V3_FPGA，3、4 = GND，5 UART_TX（FPGA→OPi），6 空（Dock 上与板载 WS2812 共用，不用），
                      7 SCR_EN，8 VD_FLT_N，9 VL_FLT_N，10 VL_OK，11 UART_RX（OPi→FPGA），12 PFAIL_N
     P2-11/12 原来打着"不连接"标记，已去掉；P2-5、P2-7、P3-6 打上不连接标记。
  3. PCB 局部改线（其余不动）：
     P1：3V3 主线改为 P1-1 →（4.2, 44.9）→（4.2, 47.1）接原竖线，避开新 GND 脚；P1-2 顶层短接 P1-1；
         LD3、LD2 改从 P1-5、P1-7 底层走到 RA8、RA7（x 6.6 / 8.4 竖段）。
     P2：3V3 主线同样从两排中间 x 4.2 绕开 P2-3；P2-2 顶层短接 P2-1。
     P3：P3-2 顶层短接 P3-1；UART_TX 从 P3-5、UART_RX 从 P3-11（顶层上到 y 81.6 接原横线）、
         SCR_EN 从 P3-7 接 x 4.2 原竖线，原 x 1.15 下行支路改接到 x 1.72 原上行线。
  4. 丝印：三个插座 1 脚旁加"1"；板名改 D1.3。
  5. FPGA 引脚约束必须同步改（fpga/el_hdmi、fpga/el_test 的 .cst，由 fpga-8c 改，需用户在那边确认）：
     上表是"Dock 第几脚 = 哪根信号"。fpga-8c 按 Dock 原理图换算的球号：
       J5：5 LD3=L9，6 LD1=N8，7 LD2=N9，8 LD0=N7，9 UD0=N6，10 UD3=D11，11 UD1=A11，12 UD2=B11
       J6：6 VD_HI_N=C12，8 VD_ON_N=A14，9 CP2=B14，10 OE_N=A15，11 CP1=D14，12 S=E15
       J14：5 UART_TX=P9，7 SCR_EN=T8，8 VD_FLT_N=P8，9 VL_FLT_N=R8，10 VL_OK=T7，11 UART_RX=T6，12 PFAIL_N=P6
     J6-11/12（D14/E15）在 Bank 1，与 HDMI 输入同 bank，CP1、S 只能声明 LVCMOS25；AHCT245 的 VIH 2.0 V，可靠识别，EL-IF 不用改。
     2026-10-22 fpga-8c 已按此表改完 el_hdmi、el_test 的 .cst（013a8d9），仿真、编译通过，与 EL_IF_D1.3.net 逐脚比对一致。
     （原 .cst 的 J5 对应表经 fpga-8c 核对是对的，此前"错开两位"是我从 PDF 抽文字时串行，不成立。）
  6. 连接：用 2×6 公对母双排杜邦线（Dock J5/J6/J14 是 2×6 母座、P1–P3 是公排针；两头 1 脚对 1 脚），两头都对准"1"；不能 180° 调头插。
     首次上电前万用表量：Dock J5-1 与 P1-1 通、P1-1 与 P1-3 不通（3V3 与 GND 不短）。

二、J_PF / J_LAMP 换成与 PCB-3 同款 HCTL XH 座（重要，已改）
  问题：PCB-3 的 J_PF 是 HCTL XH-3A（C2908601），EL-IF 的是 JST B3B-XH-A 封装，两者丝印本体朝向相反。
        按丝印焊座子后，1↔1 的直连线在 EL-IF 一头会落到 3 脚：PFAIL_N 被拉到 GND，屏幕永远不亮。
        其他所有板对板 XH 线两头都是同一种封装，只有这一根不一致。
  改法：J_PF → XH-3A（HCTL C2908601），J_LAMP → XH-2A（HCTL C2908600），与第一单买的 XH-2A/3A 同料，不用另买。
        焊盘位置、1 脚位置、网络都不变（J_LAMP 换封装后转回 0°，1 脚仍在 x 73.75 接 +12V_EL 粗线）。

三、RRX 100 Ω → 1 kΩ（一般，只换值）
  Pi 先上电、Dock 未上电时，Pi 的 TX 经 100 Ω 往 FPGA IO 和 Dock 3V3 灌电流最多约 24 mA；RTX 早已因同样理由改 1 kΩ，RRX 跟着改。

四、核对
  DRC（嘉立创两层板规则）：0 个间距/连接错误；只剩 1 条"原理图与 PCB 网表不一致"（测试点符号无封装，PCB 用自由焊盘，与 D1.2 相同）。
  网表对比 D1.2：只有 P1–P3 各脚网络按上表变化；J_PF、J_LAMP 网络不变。
  贴片件（22 个）位置、角度与 D1.2 完全相同，JLC_SMT_BOM/CPL 内容沿用 D1.2。
  铺铜已重建（顶、底两块 GND）。
