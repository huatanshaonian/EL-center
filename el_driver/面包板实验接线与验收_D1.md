# 面包板实验接线与验收 D1

日期：2026-10-18。此文是待执行实验单，尚未取得实物数据。先做直插信号/PFAIL实验，再人工限流点屏，最后验证电源保护级；通过后继续PCB布线和打板。首次点屏按根目录工程设计笔记§16.4人工顺序操作，与未验证PCB给真屏供电是两个阶段。

## A. 直插信号链，不接屏、不接12V

两片SN74AHCT245N PDIP-20跨面包板中沟放置。按缺口/圆点查顶视图：1–10沿一侧，20–11沿另一侧，不凭原理图图形位置猜针序。先万用表查面包板每排五孔、电源轨中断点和中沟隔离。

完整11路信号及所有连接器针表见[连接器与缓冲引脚表D1](连接器与缓冲引脚表_D1.md)。U1负责8路数据；U2负责CP2（2→18脚）、CP1（3→17脚）、S（4→16脚）。时钟串阻原理图47Ω、数据33Ω均是试值。实验先100Ω，再82/68/47/33Ω逐步比较，避免直接把仿真有明显过冲的初值当合格终值。

DF11为2.0mm，不直接插2.54mm面包板。用成品DF11转接线，脱离屏逐根测针号及短路。屏大电流电源不经过面包板触点。

1. 断电检查5V/GND短路、IC方向。P2-11/12、P3-6保持NC；任何Dock IO/3.3V端不得接5V。
2. 暂不接Dock信号和OE线，OE用临时10k上拉局部5V以禁用输出。5V空载先限50mA排查；异常发热/限流立即断电。该限流仅排查，不作为动态供电指标。
3. 断5V，移除临时5V上拉，再接Dock及正常3.3V OE上拉。FPGA先使OE_N=1、VD_ON_N=1，全部时钟/数据低，再恢复5V。芯片无5V时不持续送高电平；1k串阻不能代替断电隔离。
4. OE高时11路输出应由100k拉低；OE低后逐路高/低验证针序。
5. 先100kHz/1MHz单路，再约3MHz，最后目标约5.4MHz CP2及完整扫描。线尽量短（信号约10cm内）。面包板寄生不合适时改短线洞洞板，不通过限制示波器带宽来隐藏振铃。

## B. PFAIL全直插面包板

不接屏，独立稳定5V给检测电路；可调低压源模拟+24V_SENSE，先限20mA，缓慢在24→18→24V扫动。各地共地，24V只到100k上臂，不能误接比较器电源/IO。

## C. 人工限流首次点屏（设计笔记§16.4）

本阶段不需要先完成NID Remote控制。用户单通道可调电源给VD12V；VL用独立稳定5V源（NID100-5或合适5V源），同时给缓冲器供电。Dock仍按既定独立电源供电，不能从Dock的未核定5V轨给屏取电。若使用NID，累计全部外接电容，不直接照旧笔记追加100µF。

断电接好CN5：17/18=VL5V，19/20=VD12V，10/12/14/15/16=GND；对应两电源地、Dock地共地。先测线束通断和Pin1方向，不带电插CN5。

1. VD输出关。先开VL，CN5端确认4.75–5.25V。
2. Dock/FPGA输出黑场完整扫描，先OE高；核对时钟/数据后OE低，扫描稳定至少一帧。
3. 最后开VD12V。工程试验起点：VL限0.4A（电源支持时），VD先1.0A黑场/稀疏图案，确认正常再逐步到2.0A全亮；进入恒流导致电压不合格时停止并分析，不能盲目加大限流。
4. 关机先关VD，保持VL与扫描；示波器/万用表观察实际VD下降。设计笔记以VD<1V作为人工观察判据，属于方案，不是Sharp时序图规定的电压。
5. VD降下来后停扫描、信号低、OE高，最后关VL。记录自然衰减和供电顺序。

电源限流不能保证内部保险必定不熔断，输出电容储能仍会流向故障点。屏内部约200V交流驱动，按原设计笔记勿接触背部驱动电路。本阶段只做正常图案与衰减观察，不用真屏做短路或过压注入。

## D. 电源保护级，先假负载

TPS25947是2mm QFN，不能把裸件插面包板，也不以杜邦线/面包板承载VD大电流。用已核实适用的焊好评估/转接模块，或后续交嘉立创焊测试载体。当前没有已核实完整适用的成品SKU，仍待落实；直插信号/PFAIL实验可先做。

无须购买电子负载。基础稳态负载：VL用16Ω/7W（约0.31A/1.56W），VD用6.8Ω/50W铝壳配合适散热器（约1.76A/21.2W），通过端子和粗线连接。此组合不覆盖所有动态/短路工况；短路、过压故障由限能测试载体执行，不能在面包板上直接短接大电源。

CBULK5/12默认不装。先累计NID全部可见输出电容及正偏差：5V最大外接100µF，12V68µF；含EL-IF导通后的输出、C3、屏和其它支路。必要时调整容量或隔离结构，不能因两路范围不同就认定掉电顺序成立。

按原理图验证EN、故障钳位、限流、软启动、反向阻断、过压断开、OUT负尖峰。四通道同步看VL、VD、CP2和EN/OE，分次采集PFAIL、VD_HI_N、VL_OK与两个FLT。测试：正常关机、24V慢降、低压侧硬断开、Dock先断/复位、VL掉电、负载最轻/最重、快速恢复/重复启停及温度变化。市电侧沿用合规既有电源连接，不增改市电布线。

Q_VH/RVHU100k/RVHD33k/RVHP10k组成VD粗检测。测VD_HI_N释放时实际VD及后续尾段。若自然衰减过慢，再试装整组6件主动放电DNP：HCT04+5V_EL供电、1脚EN_VD/2脚DIS_DRV、100Ω栅阻、100k栅下拉、Q_DIS和100Ω3W。先假负载观察开关重叠及发热。VL也消失时不可假定放电继续。

T_VD_WAIT取VD_HI_N释放后到工程目标低电压的最坏实测尾段×2。不能直接用一帧或仿真值，也不能把VD_HI_N高解释成VD已0V。

## E. 提供给RTL的时序约定

上电：等待VL_OK高→数据/时钟初始低→OE低→开始有效完整扫描→稳定至少一帧→VD_ON_N低。

正常关机：VD_ON_N高→等待VD_HI_N高→等待实测确定的T_VD_WAIT→停止扫描、全部信号低→OE高→最后由供电侧关闭VL。

PFAIL低或VL_OK低时，硬件钳位同时动作，RTL立即令VD_ON_N高；只要VL_OK仍高便保持有效扫描。VL_OK低后不继续假定5V逻辑有效。任一FLT低则锁存故障、关VD并上报，不自动重试。故障原因查明后用户手动触发复位，工程建议VD_ON_N高至少10ms，再从上电序列开始；这10ms不是所有器件复位时长的厂家统一保证。

FPGA失去电源时不能靠RTL继续扫描。硬拔插的最终顺序必须由实际电源保持与硬件结构验证。当前未编写/验证上述RTL。
