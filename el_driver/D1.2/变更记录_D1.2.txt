一、原理图变更
1. RIL12（+12V eFuse 限流设定电阻）：1.3k 无现货 → 1.2k（MF1/4W-1.2KΩ±1%，C119326）。
   TPS259470 I_LIM = 3334 / R_ILM ≈ 2.78 A（原 2.56 A）。屏 +12V 稳态远低于此，仍能挡住短路。
   封装、脚位不变；只流过 µA 级电流，不发热。
2. J_PF：2 针 XH → 3 针（C144394，A2501 3P，与 XH 兼容）。
   1 = PFAIL_N_3V3，2 = SCR_EN_3V3（斜面"屏幕"钮子开关，开关另一端接 GND），3 = GND。
3. 新增 RSCR 10k（C119347）：SCR_EN_3V3 上拉到 3V3_FPGA。J_PF 不插时 = 允许开屏。
4. 新增 D4 BAT54WS（C191198）：K → SCR_EN_3V3，A → EN_VD。开关拨到关时直接把 VD eFuse 关掉（硬件关屏）。
5. P3-12（Dock J14-12）：原 SPARE_J14_12 → SCR_EN_3V3，FPGA 同时读开关状态（见 fpga/el_hdmi 使用说明 v0.2）。
   测试点 TP_SP3 改名 TP_SCR。
6. 新增 J_LAMP（XH 2P，C158012）：1 = +12V_EL，2 = GND。面板"屏幕供电"黄灯，跟随 EL 的 +12V。

二、PCB（第一版布局布线）
  板子：100 × 100 mm，2 层，1.6 mm；4 个 M3 安装孔（Ø3.2，中心距板边 5 mm）。
  元件 119 个 + 35 个测试点（Ø2.4 焊盘 / Ø1.0 孔，按网络命名）。
  走线 859 段、过孔 38 个（0.61/0.30 mm）；顶层、底层 GND 铺铜。
  网络类线宽：+12V_IN/+12V_EL 默认 1.5 mm，+5V_IN 1.2 mm，+5V_EL 0.8 mm，3V3 0.4 mm，GND 0.6 mm；
  电源和地的最小线宽放到 0.25 mm，只用于 eFuse（VQFN-10 2×2 mm）引脚处的缩颈。

  主要位置（mm，左下角为原点）：
    P2 / P1 / P3（接 Dock J6 / J5 / J14）  x 4.2，y 30 / 50 / 74，竖直 2×6 排针
    J_EL（接屏 CN5，DF11 弯角）           (90.7, 47)，开口朝右板边
    J_PWR（+12V、GND、+5V、GND 螺丝端子）  (72, 94)，上板边
    J_UART (16, 96)、J_PF (27.4, 96)        上板边，竖直 XH
    J_LAMP (75, 4.5)                        下板边，竖直 XH
    U1 / U2（74HCT245）                     x 50，y 51.5 / 22
    U_VD / U_VL（TPS259470 eFuse）          (93, 81) / (93, 68.5)，转 90°：输入从左、输出向右

  eFuse 区域布线（自动布线漏掉的部分，手工完成）：
    问题：TPS259470 的 IN/OUT 是 0.3 mm 宽的长条焊盘，自动布线按 1.0 mm 以上的电源线宽进不去，
          U_VD/U_VL 的 IN、OUT 共 4 条连接完全没接；周围信号线又把芯片围死。
    处理：两颗芯片转 90°，长条焊盘变成横向。
          输入：从左侧电容进，0.3 mm 缩颈约 0.85 mm 长。
          输出：向右出，经输出电容后沿右板边下行；+12V_EL 走底层（3 个过孔换层），+5V_EL 走顶层，
                到 J_EL 17–20 脚。
          输入、输出、DVDT 电容随之重新摆放；EN/OVLO/FLT/ILM 信号线重布。
    TP04（+12V_EL 测试点）移到 (98.2, 62)，就近接 +12V_EL 底层主干。

  P1–P3 封装修正：库里的 HDR-TH_12P-P2.54-V-M-R2-C6-S2.54-EH 带一个 Ø2 mm 挖槽，位于 1/2 号与相邻
    两针之间，离焊盘只有 0.05 mm，做出来会铣到焊盘。已从工程库封装中删除该挖槽（和对应的文档层圆圈）。

  DRC（嘉立创 两层板工艺规则）：0 个间距/连接错误。
    剩 1 条"网表不一致"：原理图里的测试点符号缺封装，PCB 上用自由焊盘代替，属于预期，不影响制板。

三、机械尺寸（给 3D 建模用；数据来自导出的 STEP）
  板厚 1.6；板面以上最高 14.1（J_PWR 端子），P1–P3 排针 9.5，其余元件 ≤ 7.0。
  板底引脚最长伸出 1.9 → 铜柱 ≥ 5 mm（建议 M3 × 8）。
  出线：P1–P3 杜邦线向上，排针上方留 ≥ 30；J_EL 向右插 DF11 母头，右板边外留 ≥ 25；
        J_PWR 端子在上板边，导线方向请在 STEP 里确认；J_UART/J_PF/J_LAMP 向上插，上方留 ≥ 20。
