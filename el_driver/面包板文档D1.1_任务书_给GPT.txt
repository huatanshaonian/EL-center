1. 已经确定的方案（文档必须按这些写，不要沿用旧文档的说法）
--------------------------------------------------------------------
1.1 电源条件（用户实际情况）
    - 可调电源只有 1 路。点屏时它只给 VD 12V（CN5 19/20）。
    - 5V（VL，以及缓冲器 VCC）用 USB 充电头（≥2A）+ 剪开的 USB-A 线：
      红线 +5V，黑线 GND，必须先用万用表确认；绿/白（D+/D−）剪短并分别绝缘。
      不要用 USB-C PD 充电头。
    - 不要用可调电源的 12V 再降压出 5V：那样 5V 和 12V 会同时上电、同时掉电，违反上电顺序。
    - 不要用 Dock 板上的 5V 给屏供电。
    - 屏的 VL/VD 大电流不走面包板触点，用接线端子/Wago 分线；所有地共地。
    - USB 充电头不能设限流。这一点要在文档里写明：上电前必须加倍检查接线。
1.2 不做假负载
    旧文档 A 节每路的 390Ω/10pF/1M 假负载、D 节的 16Ω/6.8Ω 功率假负载、灯泡全部删除。
    动态波形改在“接真屏、只开 VL、不开 VD”的状态下测，这是合法的上电状态，测到的就是屏真实的输入负载。
1.3 不做 NID100 Remote 控制电路，也不在面包板上做 eFuse
    TPS259470 是 2mm QFN，插不了面包板，等 PCB 阶段再验证。文档只用一句话说明即可。
1.4 PFAIL 用 D1.1 的值
    TL431AILP 代替 LM4040；RPFH 510k；电阻全部 1%。
    RPFB1 13k 在订货：到货前用 12k + 1.2k 串联代替 13k + 150Ω；
    12k 也没有时，可用 10k + 1k + 1k + 1k。
1.5 FPGA 测试时序程序（RTL）还没写
    实验 3、4 需要它。文档要写明这个前提，并列出程序需要输出什么
    （见第 3 节实验 3、4），但不要写 RTL。

2.1 “原理图 PDF 怎么看”一节（放在文档前面）
    用户看不懂 D1.1 的原理图 PDF。这份原理图是“网络标签式”画法：元件之间几乎不画连线，
    每个引脚上挂一个写着网络名的小标签，网络名相同的引脚就是连在一起的。要讲清：
    - 两个 PDF 分别是哪一块，各页大概是什么内容（按页列表）；
    - 怎么读：位号、阻值、引脚号、网络标签；网络名相同 = 电气相连；
      灰色元件 = DNP（不装）；GND/+5V 等电源符号的含义；
    - 举一个完整例子：PF_REF 网络在哪几页、哪几个引脚出现，
      把它们连起来就是 U_PF-2、U_PF-6、U_REF-1、U_REF-3、RREF-2；
    - 说明面包板上应以本文档的连线图和接线表为准，PDF 用于核对。

3. 实验清单与要点
--------------------------------------------------------------------
实验 0  到货验收（不通电）
  - 用万用表逐只量需要用到的电阻值（色环不可靠时以万用表为准）。
  - 2N3904：用二极管档找 B、E、C，确认是否为 E-B-C（平面朝自己、脚朝下、从左到右）。
  - TL431：确认中间脚是阳极 ANODE。TI 脚号为 1=CATHODE、2=ANODE、3=REF，见 TI SLVS543S 表 5-1。
  - 245、LM393 认清缺口方向；面包板先量每排 5 孔是否相通、电源轨是否中间断开。
  - 屏线：
      双头线逐针量 1-1、2-2……20-20 都导通，并量相邻针之间不短路；
      单头线给 20 根线编号；
      在屏不通电时用蜂鸣档反查 CN5：10/12/14/15/16 互通（GND），17/18 互通，19/20 互通，
      借此确认 1 脚方向。

实验 1  掉电检测 PFAIL（不需要 FPGA，不接屏）
  - 供电：USB 5V 供 PFAIL 电路；可调电源接 RPFT 上端模拟 24V，限流 20mA，两路共地。
    24V 只接 RPFT，不能碰到比较器电源脚或其他 IO。
  - 接线（D1.1 网表）：
      U_PF LM393P：8 脚 +5V，4 脚 GND；3 脚 PF_SENSE；2 脚 PF_REF；1 脚 PF_COMP；
                    5 脚 GND，6 脚 PF_REF，7 脚悬空；CPF 100nF 跨 8–4 脚
      U_REF TL431AILP：1、3 脚接 PF_REF，2 脚接 GND
      RREF 1k：+5V → PF_REF
      RPFT 100k：+24V_SENSE → PF_SENSE
      RPFB1 13k：PF_SENSE → PF_DIV；RPFB2 150Ω：PF_DIV → GND
      RPFH 510k：PF_COMP → PF_SENSE
      RPFPU 2.2k：+5V → PF_COMP
      RPFIB 68k：PF_COMP → Q_PFI 基极
      Q_PFI：E → GND，C → PF_INV；RPFIP 10k：+5V → PF_INV
      RPFD_B 10k：PF_INV → Q_PFD 基极；Q_PFD：E → GND，C = PFAIL_DOCK_N
      RPFO_B 10k：PF_INV → Q_PFO 基极；Q_PFO：E → GND，C = PFAIL_OPI_N
      测试时两路输出各用 10k 上拉到 5V；以后接 Dock/OPi 时，改为上拉到各自的 3.3V，两路不能并在一起。
  - 逻辑：24V 正常 → PF_COMP 高 → PF_INV 低 → 两路输出高（无报警）；
          24V 过低 → 两路输出低（报警）。
  - 期望值（13k + 150Ω）：
      PF_REF 2.47–2.52V；
      24V 下降约 21.0V 时报警，回升约 21.9V 时解除，迟滞约 0.9V；
      允许范围：报警 20.5–21.5V。
    用 12k + 1.2k 时：报警约 20.9V，解除约 21.9V。
  - 步骤：从 24V 以约 0.1V/步缓慢往下调，再往上调，各重复 3 次；
    记录 PF_REF、PF_SENSE、PF_COMP、PF_INV、两路输出电压。

实验 2  电平转换静态测试（不需要 FPGA 程序，不接屏）
  - 两片 245 由 USB 5V 供电；Dock 只用 USB-C 供电，只引出 3.3V 和 GND，不接 Dock 的任何 IO。
  - 先接 5V，再给 A 侧加 3.3V 高电平；断电时先撤掉 A 侧的高电平
    （A 侧 1k 串阻只能限流，不能代替断电隔离）。
  - OE_N 由 ROE 10k 上拉到 3.3V（输出禁用）时：11 路 B 侧输出都应被 RPB 100k 拉低。
  - OE_N 跳线接 GND 后：逐路把 A 侧接 3.3V/GND，在 B 串阻之后量电平。
    高 ≥ 3.5V，低 ≤ 1.5V；同时确认针号对应（按图 3 的对照表）。
  - 量 5V 电流：两片 245 静态应只有几 mA，明显偏大立刻断电查。

实验 3  动态波形（需要 FPGA 测试时序程序，未完成）
  - 前提：FPGA 能输出黑场完整扫描，以及可控的 OE_N。
  - 接真屏，只开 VL（USB 5V），不开 VD。
  - 示波器探头用短接地弹簧，在屏线末端 CN5 侧测。
  - 串阻对比：RB 依次试 100 / 82 / 68 / 47 / 33Ω，库存都有，记录每档的过冲和振铃。
  - 验收表沿用旧文档 A 节的 CN5 端验收项：
      VL 4.75–5.25V；逻辑高/低 ≥3.5 / ≤1.5V；
      峰值在 −0.3V 至 VL+0.3V；10–90% 边沿 ≤30ns；
      CP2 周期 ≥154ns，高/低宽各 ≥60ns；
      数据对 CP2↓ 建立/保持 ≥50 / ≥40ns；
      每行对 160 组、每帧 240 行对；帧率 60–120Hz。
  - 程序需要输出的内容（只列要求，不写 RTL）：
      CP2 约 5.4MHz（54MHz/10）；60Hz；每行对 160 个 CP2；每帧 240 行对；
      复位后 OE_N=1、全部输出低；
      能切换黑场 / 全亮 / 棋盘格等测试图；
      依据设计笔记 §8.3。

实验 4  首次点屏（需要实验 3 通过）
  - 依据设计笔记 §16.4 单通道方案：VL = USB 5V，VD = 可调电源 12V。
    VD 限流先 1.0A，做黑场和稀疏图案；正常后再到 2.0A 做全亮；任何时候不超过 3A。
  - 上电：可调电源输出关、USB 不插 → 断电接好线束 → 插 USB（VL）→ 在 CN5 端量 4.75–5.25V
          → Dock 上电、FPGA 输出黑场，确认 CP2/CP1/S → OE_N=0 → 最后开可调电源输出（VD）。
  - 关机：先关可调电源输出 → 确认 VD 降到 1V 以下 → 停 FPGA 时序/断 Dock → 最后拔 USB。
  - 记录：VD 实际电流、自然下降时间、亮度/闪烁现象。
  - 安全：屏内部有约 200V 交流，任何时候不碰背面驱动板；不要带电插拔 CN5。

不在面包板做：eFuse 保护级（TPS259470）、NID100 供电、主动放电电路，都留到 PCB 阶段。
