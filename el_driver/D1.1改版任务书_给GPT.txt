1. 必改项 A：U_REF 换芯片并改连接（PFAIL 原理图）
--------------------------------------------------------------------
现状：
  U_REF = LM4040AIZ-2.5/NOPB（C544355），TO-92。
  网表中 U_REF 只有 2 个引脚：2 脚 Anode → GND，3 脚 Cathode → PF_REF。
  1 脚不存在（LM4040 的 1 脚是空脚）。
改为：
  U_REF = TI TL431AILP，LCSC C72108，2.495V 可调并联基准 ±1%，TO-92（LP 封装）。
  TL431AILP 引脚（TI 规格书 SLVS543S 表 5-1，LP 封装）：
     1 = CATHODE   2 = ANODE   3 = REF
  [更正 2026-10-18] 本任务书初版把 1、3 脚写反成 1=REF/3=CATHODE。
     D1.1 已按 TI 原厂脚号建符号。因为 1、3 脚同接 PF_REF，网络拓扑不受影响。
  连接：
     U_REF-1 (CATHODE) → PF_REF      ← 新增连接，必须有
     U_REF-2 (ANODE)   → GND         （同原来）
     U_REF-3 (REF)     → PF_REF      （新符号下 3 脚为 REF，仍接 PF_REF）
  即 REF 与阴极短接，PF_REF = 2.495V。
封装：继续使用 TO-92-3_L4.9-W3.7-P1.27-L（直列 1.27mm 间距）。
  必须确认焊盘 1/2/3 与符号引脚 1/2/3 一一对应，且丝印平面方向和 TI 规格书一致。
不改：RREF = 1kΩ（+5V_IN → PF_REF），给 TL431 提供约 2.5mA 阴极电流
  （TL431 最小工作电流 1mA），保持原值。
改完后 PF_REF 网络成员应为：U_PF-2、U_PF-6、U_REF-1、U_REF-3、RREF-2（共 5 个）。
器件属性：Manufacturer=TI，Manufacturer Part=TL431AILP，Supplier Part=C72108，
  Tolerance=±1%。删掉 LM4040 的所有残留属性（描述、LCSC Part Name、数据手册链接）。

2. 必改项 B：RB9、RB10、RB11 的器件条目（EL-IF 原理图）
--------------------------------------------------------------------
现状：这 3 个电阻的 Value 和 Name 是 47Ω（“47R (trial)”），但 Device/PARTTYPE
  仍是 “TH 33Ω ±1%”。导出的网表和 BOM 会被当成 33Ω 备料。
  RB9：BUF_CP2_B → EL_CP2_5V
  RB10：BUF_CP1_B → EL_CP1_5V
  RB11：BUF_S_B → EL_S_5V
改为：建立或选用 47Ω 器件条目（例如 “TH 47Ω ±1%”），Device、PARTTYPE、Value、
  Name 全部一致为 47Ω，1/4W，1%，轴向直插 P10.5mm。连接不变。
RB1–RB8 保持 33Ω（“33R (trial)”），不改。

3. 改值项（只改阻值/器件数据，连接和封装不变）
--------------------------------------------------------------------
原因：E96 值和 0.1% 精密电阻在立创商城缺货或交期太长，已改用常备 1% 金属膜 1/4W。
每颗都要同时改 Value、Name、Device/PARTTYPE、Tolerance、Supplier Part（有编号的填上），
不能只改显示文字。

  位号    电路    网络（1脚 → 2脚）              原值             新值         LCSC
  RUV1   EL-IF  +5V_IN → EN_VL                27.4kΩ 1%        27kΩ 1%      C119356
  ROV51  EL-IF  +5V_IN → OVLO_VL              35.7kΩ 1%        36kΩ 1%      C119359
  RIL5   EL-IF  ILM_VL → GND                  4.22kΩ 1%        4.3kΩ 1%     C1744259（YAGEO MFR-25FRF52-4K3）
  RIL12  EL-IF  ILM_VD → GND                  1.33kΩ 1%        1.3kΩ 1%     C28144345（UNI-ROYAL MF0S4FF1301A50）
  RVS1   EL-IF  +5V_EL → VL_SENSE_MID         100kΩ 0.1%       100kΩ 1%     库存件，Supplier Part 留空
  RVS2   EL-IF  VL_SENSE_MID → VL_SENSE       1.2kΩ 0.1%       1.2kΩ 1%     C119326
  RVS3   EL-IF  VL_SENSE → GND                10kΩ 0.1%        10kΩ 1%      库存件，Supplier Part 留空
  RPFT   PFAIL  +24V_SENSE → PF_SENSE         100kΩ 0.1%       100kΩ 1%     库存件，Supplier Part 留空
  RPFB1  PFAIL  PF_SENSE → PF_DIV             13kΩ 0.1%        13kΩ 1%      C119350
  RPFB2  PFAIL  PF_DIV → GND                  150Ω 0.1%        150Ω 1%      C119307
  RPFH   PFAIL  PF_COMP → PF_SENSE            499kΩ 0.1%       510kΩ 1%     C119382

RPFB1/RPFB2 备注：在这两个器件的备注栏（或原理图文字注释）写
  “备选：RPFB1=12k，RPFB2=1.2k（合计 13.2k）”，器件本身仍按 13k + 150Ω 画。

改后应得到的设定值（供自查，不需要改其他器件）：
  VL 欠压 UVLO ≈ 1.2 × (1 + 27/10)     ≈ 4.44 V
  VL 过压 OVLO ≈ 1.2 × (1 + 36/10)     ≈ 5.52 V
  VL 限流      ≈ 3334 / 4300            ≈ 0.78 A
  VD 限流      ≈ 3334 / 1300            ≈ 2.6 A
  PFAIL 报警点 ≈ 2.495 × (1 + 100/13.15) ≈ 21.5 V（未计迟滞的粗算）
     [更正] 计入 RPFH 510k 正反馈后：24V 下降约 21.0V 报警，回升约 21.9V 解除，
     与原理图注释 “Trip ~21V, recover ~22V” 一致。

5. 全局属性清理（所有轴向直插电阻，含 EL-IF 和 PFAIL）
--------------------------------------------------------------------
现状：轴向电阻的实例封装是直插（P10.5mm），但导出的网表 FOOTPRINT 字段是 R0603，
  很多器件的 Power(Watts) 写 100mW。交嘉立创或导 BOM 时会被当成 0603 贴片件。
改为：
  5.1 所有轴向电阻：FOOTPRINT 导出值必须是实际的直插封装名（P10.5mm 那个），
      不能是 R0603。做法不限（改器件库条目的封装，或换成直插器件条目），
      但改完后导出的 .net 里不能再出现 R0603。
  5.2 所有轴向电阻：Power(Watts) = 0.25W。
  5.3 直插瓷片电容 C1、C2 同理：FOOTPRINT 不能导出为 C0603。
  5.4 真正的贴片件（0603/0805 电容、SOT-23、QFN 等）不要动。
